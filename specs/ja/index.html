人間用の
構成ファイル形式。

TOMLは最小限の構成ファイル形式であることを目指しており、その形式は明瞭な意味論により読むのが簡単です。TOMLはハッシュテーブルに曖昧さなく対応すべく設計されています。TOMLは幅広い多様な言語におけるデータ構造へ構文解析することが簡単でしょう。 

# これはTOML文書です

enabled = true

temp_targets = { cpu = 79.5, case = 72.0 }

[servers]

TOMLは人間を優先します

TOMLは最小の構成ファイル形式であることを目指しています。

  • 明瞭な意味論のため読むのが簡単です。
  • ハッシュテーブルへ曖昧さなく対応づきます
  • 幅広い様々な言語におけるデータ構造へと構文解析するのが簡単です
TOMLには有用な備え付きの型があります
  • キーバリュー対
  • 配列
  • テーブル
  • 行内テーブル
  • テーブルの配列
  • 整数と浮動小数点数
  • 真偽値
  • 日付と時刻、省略可能なオフセットつき
TOMLは幅広く対応されています

TOMLには既にほとんどの人気があり今日使われているプログラミング言語において実装があります：C, C#, C++, Clojure, Dart, Elixir, Erlang, Go, Haskell, Java, JavaScript, Lua, Objective-C, Perl, PHP, Python, Ruby, Rust, Scala, Swift, …… そしてもっとたくさん。

# これはTOMLのコメントです

# これは複数行の
# TOMLのコメント

強力な文字列

文字列を記述するには4つの方法があります。基本文字列、複数行基本文字列、リテラル文字列、複数行リテラル文字列です。基本文字列は引用符で囲まれます。 

str1 = "俺は文字列。"
str2 = "俺を \"引用符\" で囲める。"
str3 = "Name\tJos\u00E9\nLoc\tSF."

複数行基本文字列はそれぞれの側から3つの引用符で囲まれ、改行が許されます。すべての非空白の文字の前につく空白を自動で取り除くには、行末のバックスラッシュを含めること。 

str1 = """
Roses are red
Violets are blue"""

str2 = """\
  とりなく\
  こゑすゆめ\
  さませ。\
  """

str2は "とりなくこゑすゆめさませ。"になります（改行がなにもない単一の文です）。

リテラル文字列は一重引用符により囲まれます。 エスケープは一切行われないため、見たものがそのまま得られるものです。 

path = 'C:\Users\nodejs\templates'
path2 = '\\User\admin$\system32'
quoted = 'Tom "Dubs" Preston-Werner'
regex = '<\i\c*\s*>'

エスケープがなにもないため、一重引用符で閉じたリテラル文字列内で一重引用符を書く方法はなにもありません。ここで複数行リテラル文字列の登場です。 

re = '''I [dw]on't need \d{2} apples'''
lines = '''
最初の改行は
生の文字列から取り除かれます。
他すべての空白は
保持されます。
'''

数値

整数、浮動小数点数、無限、はては非数のすべてに対応。 科学的な記法を使うことも千刻みの区切りを使うこともできます。 

# 整数
int1 = +99
int2 = 42
int3 = 0
int4 = -17

# `0x`の接頭辞つき16進数
hex1 = 0xDEADBEEF
hex2 = 0xdeadbeef
hex3 = 0xdead_beef

# `0o`の接頭辞つき8進数
oct1 = 0o01234567
oct2 = 0o755

# `0b`の接頭辞つき2進数
bin1 = 0b11010110

# 小数
float1 = +1.0
float2 = 3.1415
float3 = -0.01

# 指数
float4 = 5e+22
float5 = 1e06
float6 = -2E-2

# 両方
float7 = 6.626e-34

# 区切り
float8 = 224_617.445_991_228

# 無限
infinite1 = inf # 正の無限
infinite2 = +inf # 正の無限
infinite3 = -inf # 負の無限

# 非数
not1 = nan
not2 = +nan
not3 = -nan

日付と時刻

TOMLの機能には、オフセット付きまたは無しの、日付、時刻、日時への対応があります。 

# オフセットつき日時
odt1 = 1979-05-27T07:32:00Z
odt2 = 1979-05-27T00:32:00-07:00
odt3 = 1979-05-27T00:32:00.999999-07:00

# 現地の日時
ldt1 = 1979-05-27T07:32:00
ldt2 = 1979-05-27T00:32:00.999999

# 現地の日付
ld1 = 1979-05-27

# 現地の時刻
lt1 = 07:32:00
lt2 = 00:32:00.999999
